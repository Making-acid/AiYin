## Docker  

###   (docker-compose)

```yaml
backend:
  build: ./backend   # Python 3.11-slim
  volumes:
    - ./backend/app:/app/app    #  
    - ./backend/data:/app/data  # /  /  
  command: uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

frontend:
  build: ./frontend   # Node 22 alpine (dev)
  volumes:
    - ./frontend/src:/app/src   # HMR
  environment:
    - VITE_API_BASE=http://localhost:8000
  depends_on: [backend]
```

## PyInstaller EXE  

###  

```bash
# 1.   VITE_API_BASE="" （  ）
npx vite build

# 2.    backend/static/（  assets/  ）
Copy-Item -Recurse frontend/dist backend/static

# 3. PyInstaller  
pyinstaller --onedir --name "IELTS Speaking" --add-data "static;static" run.py

# 4.    data/    config.json  
Copy-Item -Recurse data "IELTS Speaking/data"
Remove-Item "IELTS Speaking/data/config.json"
```

###  

|  |  |
|------|------|
| `--onedir`  `--onefile` |  onedir       |
| `sys.frozen`  |  `sys._MEIPASS`  `sys.executable`   |
|  `static/` | `--add-data "static;static"`  `_MEIPASS/static` |
|  `data/` |  onedir  `exe  /data`   `config.json`  |
|  `run.py` |  `main.py`  `__name__ == "__main__"`  PyInstaller  |

###  

1. **  assets/  **  
   `dist/` → `static/`    `assets/`    `Copy-Item -Recurse "..\frontend\dist\*" "static\"`     `Copy-Item -Recurse "..\frontend\dist" "static"`  

2. **  **  
   `sys.frozen` → `sys.executable.parent / "data"`
