# v0.3 — 2026-07-28

## 架构重构

| 模块 | 改动 |
|------|------|
| **i18n** | 从 Live2DCharacter.tsx 剥离 → `frontend/src/i18n/` 独立目录，支持多语言模板 |
| **ASR** | 新建 `frontend/src/asr/` 模块，AsrProvider 统一接口，VoiceInput 不再区分 browser/whisper |
| **API客户端** | `client.ts` 拆分为 `config.ts` + `exam.ts` + `chat.ts` |
| **后端考试流程** | `exam_service.py` 复活（会话+状态机），`scoring_service.py` 精简为仅评分 |
| **Pydantic 模型** | 全部请求模型统一到 `schemas.py`，API 文件不再内联定义 |

## 新功能

| 功能 | 说明 |
|------|------|
| **Whisper 本地 ASR** | 支持 9 个 faster-whisper 模型（tiny~large-v3），WebM→WAV 自动转换 |
| **考官台词数据化** | `dialogs.json` 管理过渡台词，不再硬编码在代码中 |

## 构建修复

- `start.bat` 设置 `VITE_API_BASE`
- `vite.config.ts` 代理 /whisper /config /exam /chat 路径
- `.gitignore` 精确排除模型文件而非整个目录

## 文件结构

- TOEFL 目录 + Whisper 模型目录均有 `README.txt` / `PLACEHOLDER.txt` 说明规划用途
- i18n 含 `_template.ts` 用于添加新语言
