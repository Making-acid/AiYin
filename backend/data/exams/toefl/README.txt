TOEFL Speaking — Planned Future Module
======================================

This directory is intentionally prepared for TOEFL Speaking support.

To implement TOEFL:
  1. Fill in meta.json with part definitions (question counts, timing)
  2. Create prompts/examiner.txt  (AI examiner system prompt)
  3. Create prompts/scoring.txt   (scoring rubric template)
  4. Create prompts/free_chat.txt (optional)
  5. Create questions/part*.json  (TOEFL question bank)
  6. Create rubrics/*.json        (TOEFL scoring criteria)
  7. Create dialogs.json          (examiner transition scripts)

Current status: PLACEHOLDER — not implemented.
IELTS is the only active exam type.
