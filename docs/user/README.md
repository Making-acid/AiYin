# 爱音 Beta 1.3 用户指南

本指南面向普通 Windows 用户，不要求编程或 AI 技术基础。

## 一、第一次使用

1. 安装并打开爱音。覆盖安装旧版本通常不会删除本地配置和历史记录。
2. 首页默认显示中文；如需英文，可在“选项 → 界面语言”切换。
3. 打开“选项”，选择 AI 服务商，填写该服务商提供的 API Key，然后保存。
4. Windows 询问麦克风权限时选择允许。
5. 先进入“自由聊天”，录制一句简单英语，确认文字识别和角色声音正常。
6. 再进入“雅思模拟”完成完整流程。

## 二、API Key 与费用

API Key 是 AI 服务商发给你的个人凭证。本软件不附送 Key、不代收服务费，也无法替你查询余额。

- 请在 DeepSeek、OpenAI、Groq、OpenRouter 等所选服务商的官方平台申请。
- 价格、免费额度和使用限制由服务商决定，启用前请自行核对。
- Key 保存在本机后端配置中，不要截图、分享或提交到 GitHub。
- 浏览器语音通常无需额外配置；Azure Speech 是可选服务，使用你自己的 Azure 账户并可能产生费用。

## 三、两种练习模式

### 雅思模拟

考试按 Part 1、Part 2、Part 3 推进。考试阶段与评分阶段相互分离：考官不会在考试过程中打分，完成全部流程后才生成练习报告。Part 3 会根据现场回答追问，但不会读取历史评分来改变本次考试。

### 自由聊天

用于低压力英语对话，不评分。历史对话保存在本机，可以继续或删除。

## 四、语音识别

- 浏览器识别：兼容性回退方案，无需模型。
- Whisper Small English：随桌面版预装，适合普通电脑，建议 8 GB 内存和 4 核以上处理器。
- Whisper Medium English：随桌面版预装，考试精度优先，建议 16 GB 内存和 8 个逻辑线程以上。
- WhisperX：英文对齐模型随桌面版预装，仅在考试结束后补充词级时间、语速和停顿证据，不参与 Part 3 出题。普通用户保持默认“自动”即可。

首次打开软件时会根据电脑配置推荐一个预装模型，用户也可以自行选择。“选项”列表中的其他模型需要连接外部模型托管方，部分网络环境可能需要 VPN；不下载它们不会影响预装模型使用。

如果麦克风无响应，请检查 Windows 隐私权限、输入设备、音量和环境噪声。网页模式建议使用最新版 Edge 或 Chrome。

## 五、角色声音

首次打开时，爱音会说明 Azure Speech 的费用与隐私边界；如果不使用 Azure，则默认使用安装包内置的 Kokoro 本地神经语音。Windows 系统语音和浏览器语音作为兼容性回退。Azure 的额度和价格可能变化，不了解时选择 Kokoro 即可。

## 六、本地数据与隐私

- 自由聊天历史、考试记忆和密钥保存在当前 Windows 用户的本机目录。
- 生成回复所需的文本会发送给你配置的 AI 服务商。
- 启用 Azure Speech 后，角色回复文本会发送给 Microsoft 进行语音合成。
- 本地考试音频分析完成后会删除临时音频。
- 不要输入身份证件、准考证号、支付资料、机密信息或无权披露的内容。

详见[隐私说明](../../PRIVACY.md)与[免责声明](../../DISCLAIMER.md)。

## 七、常见故障

### 应用没有反应或无法连接

确认“选项”页显示“已配置”，检查网络，保存服务商配置后重试。仍失败时关闭应用再重新打开，并避免同时运行多个旧版本。

### 其他模型下载失败

Small English 与 Medium English 已经预装，无需下载。如果额外模型下载失败，请检查网络与磁盘空间；部分网络环境可能需要 VPN。可随时切回任一预装模型。

### 文字正常但没有声音

检查系统音量和输出设备。Azure 配置失败不会阻止文字回复，可以切回浏览器语音。

### 人物不显示或动画卡顿

重启应用，关闭占用显卡的软件，更新显卡驱动和 WebView2 Runtime。Live2D 只影响画面，不影响文字练习。

### 覆盖安装会不会丢数据

正常覆盖安装不会主动删除用户目录中的配置、聊天和考试记忆。不要手动删除爱音使用的本地用户数据目录；重要结果建议自行备份。

## 八、分数说明

所有分数、转写与反馈都由 AI 生成，只能用于练习，可能不准确或不一致。它们不是官方 IELTS 成绩，不能用于报名、留学、签证、求职、职业注册或其他正式用途。
